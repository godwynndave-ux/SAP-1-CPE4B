    SYSTEM PROTOCOL // HOW SAP-1 WORKS

    Every instruction takes six timing pulses. T1–T3 FETCH: PC → MAR, PC + 1, RAM → IR. T4–T6 EXECUTE: depends on the opcode (upper nibble of IR); the lower nibble is the operand address.

    OPCODEEFFECT
    LDA0000RAM[addr] → A
    ADD0001A + RAM[addr] → A
    SUB0010A − RAM[addr] → A (B inverted, +1)
    OUT1110A → output terminal
    HLT1111stop the clock

    One shared 8-bit bus (the conduit) carries a single transfer per pulse. Results wrap at FFH.

      AGENT GUIDE // TUTORIAL

      1. Type X, Y, Z (hex) in QUICK LOADOUT and press BUILD, or press EDIT SEQUENCE, change any of the 16 slots, then LOAD INSTRUCTIONS.
      2. STEP runs one whole instruction. T-CYCLE advances one timing pulse. Cyan tokens show data crossing the conduit.
      3. EXECUTE auto-runs the clock; CLOCK FREQUENCY sets the delay between pulses.
      4. When HLT lands, read the result on the orbs (binary) and the output terminal (hex).
      5. REBOOT resets the registers and keeps your program.
